# Contributing Guide – iDate Server Emulator

Thank you for your interest in contributing! 
This project exists for **educational, preservation, and development purposes**, and all contributions are welcome.

Please read this guide before submitting any changes.

---

## ✅ Basic Rules

- ❌ **No direct pushes to `master`**
- ✅ All changes **must go through a Pull Request (PR)**
- ✅ Always create a **feature branch**
- ✅ Use **Conventional Commits**
- ✅ PRs are merged using **Squash Merge only**

---
