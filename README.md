# iDate Server Emulator
A custom-built **iDate server emulator** designed to revive and support legacy iDate clients for offline testing, research, and future online implementation.

This project focuses on:
- Emulating the original iDate server behavior
- Restoring core game functionality
- Providing a foundation for future online features

---

### 🚀 Features
- ✅ Server emulation for legacy iDate client
- ✅ Configuration-based settings
- ✅ UI improvements & client-side tweaks
- ✅ Avatar and character configuration syncing (WIP)
- ✅ Offline testing environment
- ✅ Reverse-engineered core functionality
